## 检查结论（先回答问题）

**当前不支持大疆无人机和主流品牌无人车的直控**，但接入这些能力的地基已 100% 备好：

| 项 | 状态 |
|---|---|
| DJI 大疆 adapter（TASK-032） | ❌ 无代码（specs/03.6：必须基于官方 DJI Cloud API/SDK，不得伪造；属 Phase 3） |
| 品牌无人车（XAG 等，TASK-033） | ❌ 无代码（需商业授权私有 API） |
| MAVLink / ROS 2 网关（TASK-030/031） | ❌ 无代码（Phase 3 优先项） |
| DeviceAdapter SDK（14 方法契约 + 能力声明） | ✅ `adapters/device/deviceadapter.go` |
| 任务安全流水线（校验→安全检查→人工批准→执行→TraceEvent） | ✅ `apps/api/internal/modules/mission/` |
| 执行链路 | ⚠️ **仅模拟路径**：API 发 NATS `mission.started` → 只有 `ctc-sim` 消费；API 从不调用 Adapter SDK，无真机指令下发通道 |

现实约束：大疆仅企业产品线（机场 Dock/经纬系列 + 上云API）对第三方开放，需企业凭证才能真机联调；主流无人车走 ROS 2 rosbridge 可真实现；MAVLink 可用 SITL 仿真真测。
