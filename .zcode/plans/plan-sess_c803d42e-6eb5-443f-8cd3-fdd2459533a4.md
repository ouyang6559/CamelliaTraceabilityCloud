## Context

用户需要 SaaS 多租户。审计结论：**多租户隔离架构已内置**（40+ 业务表 tenant_id 强制过滤、JWT 携带租户、ID 猜测跨租户全部 404 关闭），但距完整 SaaS 缺三块：① 租户生命周期（创建/列表/停用/平台管理员——现在只有 seed 能建租户）；② 自助注册；③ 前端租户上下文（/tenant 菜单死链、无租户展示）。另审计发现 6 处隔离弱点需加固（公共文件接口未绑定溯源链、`PATCH /users/{id}` 跨租户写 user_roles、sync run 全租户触发、~10 处创建接口仅 FK 校验未验引用归属、登录多租户歧义、无隔离测试）。

用户已确认：自助注册 + 平台创建（都做）；平台管理做 API + 页面；隔离全部加固。

## 实施

### 1. 数据模型 + 平台管理员（migration + 启动自举）
- `migrations/0010_saas_multi_tenant.sql`：`ALTER TABLE users ADD COLUMN IF NOT EXISTS is_platform_admin BOOLEAN NOT NULL DEFAULT false;` + 插入系统租户 `code='platform'`（ON CONFLICT DO NOTHING）。
- `apps/api/internal/config/config.go`：新增 `CTC_PLATFORM_ADMIN_PASSWORD`（默认 `platform123`，同 seed 密码的告警模式）、`CTC_REGISTRATION_ENABLED`（默认 true）。
- `apps/api/internal/app/app.go` 启动时 `identity.EnsurePlatformAdmin(ctx, pool, cfg, log)`：确保 platform 租户 + `is_platform_admin=true` 的 `platform` 用户存在。日志告警默认密码（同现有 JWT 告警模式）。

### 2. 身份链改造（identity 模块）
- `pkg/ctxid/ctxid.go` + `middleware/auth.go`：Claims/Identity 增加 `PlatformAdmin`；`HasPerm` 平台管理员恒真；JWT issue/parse 增 `pa` claim。
- `apps/api/internal/modules/identity/auth.go`：
  - 登录修复：无 tenant_code 且密码命中多个租户 → 返回 409 `{code:"MULTI_TENANT_AMBIGUOUS", tenants:[{code,name}]}`（先验证密码再返回，防枚举）；前端弹出租户选择。
  - platform 用户登录 → `PlatformAdmin=true`、tid=platform 租户、perms=`["*:*"]`。
  - 登录（含 tenant_code 路径）与 refresh 均校验 `tenants.status='active'`（挂起租户拒绝；30min token 窗口在 ADR 说明）。
- 新文件 `apps/api/internal/modules/identity/saas.go`：
  - `ProvisionTenant(ctx, pool, input)`：事务内建租户（code 自动生成唯一）+ 3 内置角色 + 权限绑定 + 管理员用户（seed.go 重复逻辑收敛到此，seed 改为调用）。
  - `POST /auth/register`（公开；`CTC_REGISTRATION_ENABLED=false` 时 403）：{tenant_name, username, password, email?} → ProvisionTenant → 直接返回 token 对（自动登录）。
  - 平台端点（`RequirePlatformAdmin` 中间件，新 403 路径）：`GET /platform/tenants`（列表 + 用户数/基地数统计 + search/status 过滤）、`POST /platform/tenants`、`PATCH /platform/tenants/{id}`（name/status suspend|active）、`POST /platform/tenants/{id}/reset-admin-password`（重置该租户最早的 tenant_admin 用户密码）。
  - `GET /auth/me` 增加 `platform_admin` 字段；`tenant` 结构已有。

### 3. 隔离加固（审计 6 项全修）
- 新建 `apps/api/internal/pkg/tenantref/tenantref.go`：白名单表映射 + `Exists/MustExist(ctx, pool, tenantID, table, id)` 归属校验助手（未知表拒绝）。
- 引用归属校验（各 create 一两行调用）：
  - `trace/codes.go createCode`：ref_type→表映射校验 ref_id/product_batch_id/package_id 归属（防跨租户铸造二维码——审计最高危项）。
  - `trace/api.go createEvent`：farm/plot/crop_batch/task/device/mission 非空即校验。
  - `evidence create`：trace_event_id 归属校验；`ai review`：job 租户校验；`sync createTask`：platform 归属；`production createMovement`：warehouse 归属；`agriculture createTask/createTaskRecord/createInputUsage`：plot/crop_batch/task 归属；`mission createMission`：device 归属；`device createDevice`：model/farm/plot 归属。
- `identity/users.go setRoles`：先校验目标用户属于调用者租户（修复跨租户 DELETE user_roles）；`identity.go loadPerms` 增 `roles.tenant_id` 校验。
- `files/files.go ServeEvidenceFile`：SQL 加 EXISTS 绑定——evidence 的 (ref_type,ref_id) 必须存在 active trace_code（文件仅在公开溯源链上才可匿名读取）。
- `sync/sync.go RunOnce(ctx, tenantID)`：worker 传 `""`（全租户），`POST /sync-tasks/run` 传调用者租户（只触发本租户到期任务）。

### 4. 前端（admin-web）
- `stores/auth.ts`：持久化 tenant {id,name,code} + platform_admin（来自登录响应）。
- `pages/Login.tsx`：处理 409 MULTI_TENANT_AMBIGUOUS（弹出租户选择回填 tenant_code）；新增「注册新租户」切换表单（调 /auth/register，成功自动登录）。
- `layouts/AdminLayout.tsx`：顶栏显示当前租户徽标；platform_admin 显示「平台管理」菜单。
- 新 `pages/PlatformTenants.tsx`：租户表格（search/status 过滤、用户数统计）+ 创建弹窗 + 停用/启用 + 重置密码；路由 `/platform/tenants`。
- 新 `pages/TenantInfo.tsx`：当前租户信息 + 名称编辑（tenant:update 权限）；`App.tsx` 加路由 `/tenant`、`/platform/tenants`（修复死链菜单）。
- i18n 补 zh/en 词条。
