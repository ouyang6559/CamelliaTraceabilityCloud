# 22 开源贡献规范

## Issue

必须说明：

- 问题
- 复现步骤
- 环境
- 预期
- 实际

## Pull Request

必须包含：

- 变更说明
- 影响模块
- 数据库变化
- API 变化
- 测试
- 文档
- 安全影响

## Adapter PR

额外要求：

- 官方协议/文档来源
- Capability mapping
- Simulator
- Integration test
- credential handling
- rate limit handling

## Breaking Change

必须经过 RFC。

## Commit

使用 Conventional Commits。
